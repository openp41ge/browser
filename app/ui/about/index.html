openp41ge explorer is a browser built for enjoying the web. Webpages and webpage management are first-class. Webpages can be placed side by side and resized as you need within a single window. Webpages within a cell can be filtered to help you find that one page amongst many that you are looking for.

It's free, open source, and released alongside the openp41ge code editor.

# Release notes

One file per release, `<version>.md` (e.g. `0.1.3.md`), in Markdown. The
release workflow won't publish a version without one. Installed apps show
the notes in their update dialog, a small panel, and the GitHub release
shows them too.

Write them for people using the browser, not for developers: a heading and
a few short points on what's new or fixed.

```markdown
## What's new in 0.1.3

- Windows are named "openp41ge explorer — <page>" in Mission Control and
  the Window menu.
```
